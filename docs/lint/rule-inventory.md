# Rule inventory

**Inventory contract:** 65 unique Issue #10 IDs: 12 required for v1 and 53 deferred. The required rules are implemented for the narrow proof shapes below. Coverage still discloses dynamic reachability gaps and project rules selected without their required contracts; unsupported facts never become empty-success claims.

For every required rule, add a positive fixture, at least two legitimate counterexamples, contextual evidence, suppression coverage, text and JSON snapshots, and specialization/coverage checks where applicable. Record code, group, severity, confidence, proof, non-triggering forms, output, context, and cost in its rule contract fixture.
